One line for the Laugh Track: The Crypto Trading Joke Contest — a crypto trading joke, exactly 110 characters.

## The joke

> I bought the dip. Then the dip bought a shovel, dug deeper, and now I own a very expensive hole in the ground.

## Run

```sh
node main.ts
```

Reads `entry.txt` from the repo root and writes the joke to `output.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`, defaulting to `out/`).
